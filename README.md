# MOODEE PWA preview

Isolated test deployment: https://nazwansm.github.io/moodee-pwa-preview/

Source: i0kyung/moodee, branch feature/pwa-phone-notifications. The production MOODEE site is not deployed by this repository.

Install from Safari Add to Home Screen on iOS 16.4+ or Chrome Install app on Android. Open Home -> Install & phone reminders -> Enable phone reminders -> Send test, then close the app and check the lock screen.

Preview storage and permissions are separate from production. No Google account is required for notifications; anonymous Supabase authentication is used. No backend secrets are included in this repository.
